ESP32 Developer Hook & WebSocket Integration
Ready for Wiring to Physical Hardware

To wire this dashboard to your physical ESP32, broadcast either a single amplitude value or a 5-element JSON array of frequency bands over the WebSocket channel:

// Example JSON packet sent by ESP32:
{ "type": "audio_frame", "bands": [18.5, 42.1, 88.0, 61.2, 33.4], "amplitude": 2480 }
Available front-end integration hooks in app.js:
connectWebSocket("ws://esp32.local:81");
updateVisualizerData(amplitude); // 0 - 4095 or 0.0 - 1.0
updateEqualizerBands([b0, b1, b2, b3, b4]); // 5-band array
